# human-centered-systems
## A Git repo for the University of Pittsburgh's Human-Centered Systems course for group members Sophie Allen, Francisco Lara, and Nidhi Mendu.

This repository currently stores the medium-fi prototype. The medium-fi prototype has very basic functionality (basic button switching and temporary pop-up screens until data can be injected).

As of Oct. 28 2026, the hi-fi prototype has not been established and the medium-fi implements simple functions such as switching between the 'home' page and other pages, and the ability to select certain buttons. It was inspired by the simple, medium, and complex task flows and elaborated on the idea of gamifying the user's mentality surrounding fitness (to shift from negative views to more positive views and allow users to discover how they can stay active outside of going to the gym). 

Colors used for this were inspired by the University of Pittsburgh's school colors of golds/yellows and blues, and the rewards game system was inspired by the Duolingo gaming system.
